# MarkGo roadmap

Direction, not release promises. Current behavior is in the [writing guide](docs/writing.md); acceptance is in [beta gates](docs/development/beta-delivery.md).

1. Validate native input methods, file workflows, recovery failures, accessibility and display scales.
2. Refine complex Markdown and measure large-document responsiveness while preserving plain source and one-step undo.
3. Add editable tables, image insertion, formula rendering and HTML/PDF export as complete workflows.
4. Deliver verified signed packages and a documented update path per release platform.
5. After core beta quality, add explicit provider/context selection and reviewable, undoable AI edits. No mandatory cloud, telemetry, subscriptions or proprietary format.
